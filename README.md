# Overview

This project aims to predict real estate property prices based on various features such as location, size, number of rooms, amenities, and other relevant factors.
It uses machine learning algorithms to analyze historical housing data and generate accurate price estimates.

The system helpsin buyers estimate fair property prices.

# Objectives 

Build a predictive model for house/property prices.

Perform data preprocessing and feature engineering.

Compare multiple ML algorithms.

Evaluate model performance using standard metrics.

Programming Language: Python
